# OptiScaler 简体中文翻译表
#
# 编码：UTF-8（有无 BOM 均可）
# 位置：lang\zh-CN.txt，即与 OptiScaler.dll 同级的 lang 文件夹内
# 启用：OptiScaler.ini 中 [Menu] Language=zh-CN（或 auto 跟随系统语言）
#
# 格式：
#   英文原文=中文翻译
#
#   1. '=' 两侧的空格会被忽略，但 '=' 本身不能出现在英文原文里。
#   2. 以 # 或 ; 开头的行是注释，空行会被跳过。
#   3. 支持 \n（换行）、\t（制表符）、\\（反斜杠）三种转义。
#   4. 带格式符的字符串（如 %s、%d、%.2f）翻译后必须保持相同数量的格式符，
#      否则该条会被拒绝并写入日志。%% 是字面百分号，不计入。
#   5. 英文原文必须与 menu_common.cpp 里的字面量完全一致（区分大小写）。
#   6. 标签里的 "##xxx" 后缀是 ImGui 的内部 ID，不要写进英文原文里。
#
